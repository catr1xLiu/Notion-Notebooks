For a point on a unit circle with angle θ\thetaθ﻿:

  • y=sin(θ)y = sin(\theta)y=sin(θ)﻿
  • x=cos(θ)x = cos(\theta)x=cos(θ)﻿
  • yx=tan⁡(θ)\frac{y}{x} = \tan(\theta)xy​=tan(θ)﻿

Hyperbolic functions are defined using exponential functions and model the shape of a hanging string with uniform tension.
