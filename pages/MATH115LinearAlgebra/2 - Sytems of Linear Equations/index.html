2. Systems of Linear Equations

Solving equations is one of the most common tasks across multiple scientific disciplines. A lot of the time the equations are nonlinear, which do not have a general solution method.

However, when they are linear, we can develop a systematic process to identify the solutions.

  • The expression a1x1+a2x2+⋯+anxn=ba_1 x_1 + a_2 x_2 + \cdots + a_n x_n = ba1​x1​+a2​x2​+⋯+an​xn​=b﻿ is called a linear equation with n variables.
  • The values ai∈Ra_i \in \mathbb{R}ai​∈R﻿ are the coefficients.
  • The values xi∈Rx_i \in \mathbb{R}xi​∈R﻿ are the unknowns.
  • The value bbb﻿ is called the constant term.
  • Whenever we have more than one such equation, we call them a system of linear equations.

Two linear systems are equivalent if they have the same solution set(s).

To solve a linear system, we want to manipulate its augmented matrix until we can directly read the-off its solution (set).

We must preserve its solution set throughout the process. To do so, we can perform three kinds of operations called the Elementary Row Operations (E.R.O.s) that will give us a new and equivalent system:

  1. Swapping two rows
  1. Adding (or subtracting) a multiple of a row to another row
  1. Multiplying a row by a non-zero value

As long as we stick to using EROs, our systems will maintain the same solution throughout.

When we have more unknowns than independent equations (like in the example above), some variables can be chosen freely. We call these free variables.

Theorem: After applying EROs to reduce a system to a simpler form, if the j-th column corresponding to variable xjx_jxj​﻿ does not contain a leading non-zero entry in any row, then xjx_jxj​﻿ is a free variable.

To systematically solve linear systems, we aim to transform matrices into special forms:

A matrix is in Row Echelon Form if:

  • All zero rows are at the bottom
  • The first non-zero entry in each row (or pivot) occurs to the right of the leading entry in the row above.
  • All entries below a leading entry are zero.

A matrix is in Reduced Row Echelon Form if it:

  • Is in Row Echelon Form
  • Each leading entry (pivot) is 1
  • Each leading 1 is the only non-zero entry in its column
